canary-ollama

Audit your Ollama models for poisoning — chat templates, tokenizer seams, metadata.

Why this exists

Ollama models ship from the open internet and get loaded into a process with full access to your machine. Model poisoning is peer-reviewed, real, and growing.

Quick start

git clone git@github.com:room101-dev/canary-ollama.git
cd canary-ollama
./check-ollama.sh                  # list all local models
./check-ollama.sh some/model:tag   # scan one model

Requires: bash 4+, jq, c4nary (pip install c4nary).

Model location

Auto-detects (first match wins):

  • $OLLAMA_MODELS if set
  • $HOME/.ollama/models (default user install)
  • /usr/share/ollama/.ollama/models (system install)
  • /var/lib/ollama/.ollama/models (system install)
  • /mnt/ai-models/Ollama/models

Honest scope

⚠ This audits GGUF metadata / chat template / tokenizer, not billions of tensor weights. Tensor-level backdoors need white-box weight inspection. Treat this as the first, cheap layer of defense-in-depth.
